## 📌 Project Title
Farmers manage multiple fields with different crops and cultivation stages, requiring information about planting, irrigation, fertilizers, pests, and harvesting.

## 📝 Project Statement
Build a farm-management platform that organizes crop activities across fields.

## 🎯 Objective
Provide: **field profiles · crops · cultivation stages · irrigation records · fertilizer activities · pest observations · harvest status.**

## ✨ Features
| Feature | What it does |
|---|---|
| 🗺️ Field profiles | Every field has a crop, area and real crop photo. **Tap a field to open its full page.** |
| 🌱 Cultivation stages | Sowing → Growing → Flowering → Ready → Harvested. Tap a step to update. |
| 💧 Irrigation records | Write when each field was watered |
| 🌿 Fertilizer activities | Record fertilizer given to each field |
| 🐛 Pest observations | Note insects or disease on a crop |
| 🧺 Harvest status | See which crops are ready to harvest |
| 📊 Farm care score | Shows how many fields have water + fertilizer records |
| 🗣️ 3 languages | English, हिन्दी (Hindi), தமிழ் (Tamil) |
| 🤖 Farm Friend chatbot | Explains everything in simple words in all 3 languages, with voice input and read-aloud |
| 📱 Mobile friendly | Works on any phone |

## 🌾 Crops
