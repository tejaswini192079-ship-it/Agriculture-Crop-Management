# Harvestly — Farm Management Platform

A colorful, responsive front-end farm-management prototype built with **HTML, CSS, and vanilla JavaScript**. No React, build tools, backend, or external database are required.

## Run locally

1. Download and extract the project ZIP.
2. Open `index.html` in a modern browser, or open the folder in VS Code and use Live Server.
3. Choose Farmer or Administrator from the top selector to explore the simulated views.

## Files

- `index.html` — page structure and modal container
- `styles.css` — responsive styles, colorful cards, dashboard and crop flowchart
- `app.js` — demo data, forms, navigation, reports, charts, filters, export and local storage
- `indian-farm-sunrise.jpg` — generated hero image
- `indian-crop-gallery.jpg` — crop photo collage used in the visual gallery and farm cards

## Features

- Illustrated dashboard hero with dynamic farm summary
- Summary cards, crop-distribution donut chart, and cultivation-stage bar chart
- Cultivation workflow from land preparation through harvest
- Crop image cards for rice, wheat, maize, and cotton
- Farm and field management with add/edit/delete, search and filters
- Crop cycles with crop-specific growth-stage options
- Irrigation, fertilizer and pest-observation records
- Harvest records, detailed reports, CSV export and JSON backup/import
- Simulated farmer and administrator views
- Browser `localStorage` persistence and reset-demo-data option
- Responsive desktop and mobile navigation

## Important limitations

- All sample farmers, activities and records are fictional demo data.
- Role switching is simulated; it is not real authentication or security.
- Data is saved only in the current browser and does not sync between devices.
- No live weather, sensor data, AI pest detection or agronomic recommendations are provided.
